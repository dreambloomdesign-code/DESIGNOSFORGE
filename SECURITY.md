# Security Policy

## Supported Versions

The current supported line is `v1.5.x`.

## Reporting

Please open a private security advisory or contact the repository owner through GitHub if you find a vulnerability.

Do not publish secrets, exploit details, private prompts, API keys, credentials, generated private images, or personal context in public issues.

## Sensitive Data

DESIGNOSFORGE intentionally excludes:

- API keys and credentials
- private conversation logs
- raw personal context
- model weights
- generated private images
- private client assets
