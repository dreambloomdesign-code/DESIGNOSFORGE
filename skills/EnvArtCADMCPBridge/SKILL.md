# EnvArtCADMCPBridge

CADMCP bridge for environmental-art and spatial-production workflows.

Use for CAD health checks, DXF inspection/audit, DWG Core Console workflows, AutoCAD COM, Tianzheng component routing, semantic layers, geometry locks, and construction drawing QA.

Rules:

- preserve source geometry
- do not beautify away walls, openings, axes, dimensions, roads, or site boundaries
- place analysis overlays above locked base drawings
- validate with CAD/DXF audits when possible
